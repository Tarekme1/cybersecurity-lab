# Cybersecurity SOC Lab

This project documents my personal cybersecurity lab built using VirtualBox.

The goal is to simulate real-world cyber attacks and practice threat detection similar to SOC environments.

## Lab Architecture

Attacker Machine:
- Kali Linux

Target Machine:
- Ubuntu Server

Security Monitoring:
- Wazuh SIEM

## Objectives

- simulate cyber attacks
- detect threats
- analyze logs
- practice SOC operations
- understand real attack patterns

## Tools Used

- Kali Linux
- Ubuntu Server
- VirtualBox
- Nmap
- Wireshark
- Wazuh
