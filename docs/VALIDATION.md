## Exercise record

1. **Question:** What security-relevant behavior should the exercise produce?
2. **Scope:** Which lab-owned systems were involved? Use non-sensitive aliases.
3. **Activity:** Describe the authorized, controlled test at a high level.
4. **Expected telemetry:** Identify the Ubuntu log source and any expected Wazuh rule *after verifying it*.
5. **Observation:** Record actual event time, rule ID (if any), and a redacted log excerpt or screenshot.
6. **Analysis:** Explain whether the observed evidence supports the expected detection.
7. **Outcome:** Pass, fail or inconclusive, with the reason.

## Publication checklist

- [ ] The result was observed on the actual test environment.
- [ ] Logs, screenshots and configurations contain no secrets or personal identifiers.
- [ ] Evidence distinguishes successful detections from missing or inconclusive signals.
- [ ] Limitations and unresolved results are stated explicitly.
